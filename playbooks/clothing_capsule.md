# Clothing Capsule for Travel

**What this playbook claims:** a capsule wardrobe is a mix-and-match matrix, not a packing list — a locked, narrow color palette plus a small set of garments where any top works with any bottom. This method scores each garment on two independent axes (how many use-modes it covers, how well it avoids reading as an obvious tourist) and caps the total kit size, so the wardrobe stays small without collapsing into a one-outfit trip. The matrix below is a worked example built around real product recommendations; swap in your own garments and keep the structure — palette, multi-use minimum, gray-man tier check, hard ceiling.

## The locked palette

Restrict the palette before picking garments, not after. A capsule only works if every top pairs cleanly with every bottom, and that's only realistic with a narrow, deliberately boring color range.

- **Bottoms:** one charcoal grey, one khaki, one olive. A dark indigo jean is a reasonable fourth if you need a formal-adjacent option.
- **Tops:** white, light grey, navy, light blue, charcoal, olive. No prints, no logos, no graphic tees — treat any of these as noise against the palette.
- **Outerwear:** black, dark navy, or charcoal only.
- **Footwear:** black or earth-tone.

Anything outside this range doesn't go in the capsule — not because the color is bad, but because it breaks the pairing guarantee the whole system depends on.

## Scoring each garment

Every candidate gets scored on two independent axes before it earns a slot:

**Multi-use score (1–5).** Count how many of your travel use-modes the garment genuinely covers. A reasonable default set is *athletic* (gym or outdoor activity), *formal-adjacent* (a work dinner, an upscale restaurant), *everyday*, and *travel day* (airports, long transit). A garment that only serves one mode is a single-use item and doesn't belong in a bag built around a capsule. The floor worth holding: **at least 3 of 4 modes** per garment.

**Gray-man tier compliance.** Separately, score how well the garment avoids reading as an obvious tourist, or an obvious outdoor-gear tourist — logos, technical silhouettes (cargo pockets, roll-up snaps, mesh panels), and brand recognition all count against it. The full tier framework — Tier 1, essentially unrestricted, through Tier 4, conscious minimization — lives in [gray-man tier framework](../frameworks/situational_awareness.md); this file only needs the shorthand. **Tier 1–2 ✓** means an item passes in low-to-moderate-threat regions without a second thought; a caveat like "reads as an outdoor enthusiast" flags where it doesn't quite earn that.

## Worked example matrix

| Slot | Example pick | Mode coverage | Tier check | Multi-use score |

| Pant — primary | A technical stretch pant built for outdoor activity (e.g. Outlier Slim Dungarees, Fjällräven Abisko) in a neutral colorway | 4/4 | Tier 1–4 ✓ | 5 |
| Pant — formal-adjacent | Dark indigo jean or dark chino | Formal + everyday + travel | Tier 1–4 ✓ | 3 |
| Shirt — button-up | A no-logo, natural-fiber button-up (e.g. Muji) in white/grey/navy/light blue | 4/4 | Tier 1–4 ✓ | 5 |
| Shirt — short sleeve | Merino tee, 2–3 colors from the palette | 4/4 | Tier 1–4 ✓ | 5 |
| Mid-layer | Merino crew or technical fleece | Athletic + everyday + travel | Tier 1–4 ✓ | 4 |
| Shell — hard | A minimalist, low-recognition technical shell (e.g. Patagonia Torrentshell, Arc'teryx Beta without the logo colorways) in a dark colorway | Athletic + everyday + formal-adjacent-in-city | Tier 1–2 strong; pack-only in tropical climates where a hardshell reads odd | 4 |
| Shell — packable / wind | Compressible wind shell (Patagonia Houdini-class) | Athletic + everyday + travel | Tier 1–4 ✓ | 3 |
| Sock — daily | Single brand, 3–5 identical pairs | 4/4 | Tier 1–4 ✓ trivially | 5 |
| Underwear | Single brand, 5–7 identical pairs | 4/4 | Tier 1–4 ✓ trivially | 5 |
| Footwear — primary | Minimalist, wide-toe-box shoe (e.g. Altra Lone Peak, Vivobarefoot Gobi) in black | Athletic + everyday + travel; not formal | Tier 1, 3, 4 ✓; can read as "barefoot enthusiast" in fashion-conscious EU cities | 4 |
| Footwear — secondary | Clean dark sneaker or dark Chelsea boot | Formal + everyday + travel | Tier 1–2 ✓ for EU urban blending | 3 |
| Belt | Single neutral, black or dark brown | 4/4 | Tier 1–4 ✓ | 5 |
| Headwear | Low-profile cap or beanie, charcoal or black | Athletic + everyday + travel | Avoid the US-baseball-cap silhouette specifically | 3 |
| Sunglasses | No visible logo, no luxury-brand marker | Athletic + everyday + travel | Tier 1–4 ✓ if unbranded | 3 |

Named products above are recommendations, not requirements. The reasoning — multi-use floor, palette lock, tier check — is what transfers; the specific brand doesn't have to.

## The mix-and-match rule

A capsule is only as good as its worst pairing. Self-test it directly: **any top × any bottom has to look intentional.** If your merino tee in white doesn't work over your formal-adjacent pant in dark indigo, one of the two is wrong for this capsule — fix the garment, not the rule.

A handful of core rows — primary pant, both shirts, mid-layer, hard shell, daily sock, underwear, both footwear rows, belt — will drive most days of wear; everything else is situational. Keep the total capsule, garments plus footwear, to **25 pieces or fewer**. That ceiling is doing real work: it's what forces the multi-use minimum and the palette lock in the first place, rather than letting the kit quietly grow into a second wardrobe.
